# Mensagem para o grupo — POO II

Pessoal, decidimos desenvolver um **Sistema de Gestão de Biblioteca** em Java, em vez do sistema de água, para manter o projecto pequeno e focado nos conteúdos de POO II.

A aplicação terá três módulos: **Livros, Leitores e Empréstimos**. Vamos utilizar **Java Swing, MVC, JDBC com MySQL e Threads (SwingWorker)**. Não vamos implementar login, multas, reservas ou relatórios complexos.

**Divisão proposta para seis elementos:**
1. Model e validações (fácil).
2. Interface e Controller de Livros (médio).
3. Interface e Controller de Leitores (médio).
4. Interface e Controller de Empréstimos (difícil).
5. JDBC, DAOs e base de dados (médio/alto).
6. Janela principal, Threads e integração (médio).

A documentação, os contratos entre classes, as regras de negócio e as instruções do GitHub estarão no repositório `biblioteca-poo2`, na pasta `docs/`.

**Antes de começar:** cada pessoa deve ler `README.md`, `docs/03_ARQUITECTURA_CONTRATOS.md` e `docs/04_TAREFAS.md`. Trabalhem nas branches atribuídas e evitem mudar assinaturas sem combinar com o grupo.

O objectivo é termos um produto pequeno, funcional, fácil de apresentar e que todos consigam explicar ao docente.
